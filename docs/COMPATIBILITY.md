# Compatibility

Verified on 2026-11-15 against Mojang's version manifest, `meta.fabricmc.net` and the Modrinth API.

## Supported versions

Stabled supports every Minecraft: Java Edition **release from 1.20.1 to 26.3** (23 versions). Each one has its own Stabled client jar, bundled with the launcher, and its own pinned performance stack.

| Component | Version | Notes |
| --- | --- | --- |
| Minecraft: Java Edition | 1.20.1 – 26.3 (releases only) | Up to 1.21.11 obfuscated; 26.x unobfuscated |
| Java runtime | Mojang `java-runtime-gamma` (17) for 1.20.1–1.20.4, `delta` (21) for 1.20.5–1.21.11, `epsilon` (25) for 26.x | Downloaded from Mojang's runtime manifest, shared by Saves |
| Fabric Loader | 0.20.1 (stable) for every version | Launch profile from `meta.fabricmc.net` |
| Stabled Client | 1.0.0, one jar per Minecraft version | Bundled with the launcher; required |
| Build toolchain | Fabric Loom 1.19, Gradle 9.8.2, JDK 25 | `fabric-loom-remap` with Mojang mappings up to 1.21.11, non-remapping `fabric-loom` for 26.x |

Create Save lists older releases as not supported; snapshots and pre-releases are not offered. A Save keeps the Minecraft version it was created with.

## Pinned performance stacks (`launcher/src-tauri/stack/stacks.json`)

Generated by `tools/update_stacks.py`: for each version it takes the newest Modrinth build of each mod that declares support for that exact Minecraft version (a release where one exists, otherwise the newest beta), verifies the file's SHA-512, reads its `fabric.mod.json` and checks its Minecraft range, dependencies and declared `breaks` against the rest of the stack. Files are downloaded from Modrinth's CDN onto the user's computer at install time and verified again; Stabled does not redistribute them.

Fabric API is required by the Stabled client; the other mods are optional (disable, remove, restore). Roles and licences: Sodium — rendering (Polyform Shield 1.0.0); Lithium — game logic (LGPL-3.0); FerriteCore — memory (MIT); ImmediatelyFast — HUD/text/immediate-mode rendering (LGPL-3.0); EntityCulling — skips hidden entities (tr7zw Protective License).

**Beta components** (labelled "Beta" in Create Save and the mods list): FerriteCore 6.1.1 on 1.20.5 and 1.20.6, and Sodium 0.6.13 on 1.21.5 — no release build exists for those versions.

**Gaps**: FerriteCore and EntityCulling publish no Fabric build for 1.20.3 or 1.21.2, so those two versions have four performance mods instead of six. Create Save says so.

Mod Menu and Iris are **not** in any stack. Users may add their own mods; Stabled's metadata checks flag declared conflicts.

## The Stabled client on each version

The same features on every version: Stabled main menu, pause menu and Stabled Settings, the five-step introduction, the FPS display, motion blur and Discord Rich Presence. Differences come from Minecraft itself:

| Feature | Difference |
| --- | --- |
| Frosted Glass menus | The pause and settings screens blur the world behind them on 1.20.5 and newer, which have a menu blur. 1.20.1–1.20.4 have no menu blur, so Frosted Glass there means translucent surfaces only. |
| Graphics API switch (OpenGL/Vulkan) | Only on 26.2 and 26.3, the versions that have a Vulkan renderer. Elsewhere the Performance page shows the renderer (OpenGL) without a switch. |
| Performance presets | From 1.21.11 Stabled applies Minecraft's own graphics presets. Older versions have only Fast/Fancy graphics, so the preset sets the same core options itself: graphics mode, render and simulation distance, smooth lighting, clouds, particles, entity shadows, biome blend and entity distance. |
| Motion blur | Same effect everywhere; three implementations (see [ARCHITECTURE.md](ARCHITECTURE.md#in-game-client)). |

## Renderers

| Renderer | Status |
| --- | --- |
| OpenGL (every version) | Tested on every version: menus, introduction, FPS display, motion blur (Mesa llvmpipe, OpenGL 4.5 core) |
| Vulkan (26.2, 26.3) | Tested on both: same features (Mesa lavapipe, Vulkan 1.4) |
| Iris shader packs | Not in the stack. If a user installs Iris and a shader pack is active, motion blur is disabled with an explanation, because shader packs replace the renderer it runs in |

Testing used software renderers in a Linux container; see [TESTING.md](TESTING.md) for what still needs a Windows PC with a real GPU.

## Unsupported

- Minecraft releases before 1.20.1, snapshots and pre-releases.
- Forge, NeoForge and Quilt mods (detected and flagged).
- The launcher and PC Optimiser target Windows 10/11 x64. Linux builds exist only for development (no persistent sign-in, optimiser unavailable). macOS is not supported.
